    1The idea

    The car never sees the world. It sees messages.

    Every V2X decision runs on a belief rebuilt from messages. A failure can come in anywhere along this chain.

    WorldW

    Stale but detectable

    Loss or delay ages the data. The app can notice and fall back safely.

    Fresh but wrong

    The message looks current but is wrong. The vehicle trusts it.

    Silent by absence

    A conflicting vehicle never transmits, so the app cannot see it.

    2Method

    One prompt in, one minimal failure out

    The LLM interprets the prompt. Fixed rules check feasibility and decide whether a failure counts.

    1. I

      LLM Agent Analysis

      Parses the prompt into a typed spec. An Age-of-Information check rejects faults that cannot matter.

    2. II

      Scenario Grounding

      Retrieves road, V2X and driver knowledge. The planner assigns agents to real lanes.

    3. III

      V2X Synthesis

      SPaT, MAP and BSM pass through a spatial channel and fault injection, next to a ground-truth twin.

    4. IV

      Refinement

      Search and LLM self-reflection repair weak tests. Delta debugging reduces each failure to one fault.

    3Paired rollout replay

    Same traffic, two egos, one difference

    5Results

    What the experiments show

    100 plain-language prompts compile, ground and run, with zero false failures.

    100/100 executed 365/367 clean spawns 0 false admissions

    Search and self-reflection turn weak fault tests into verified failures.

    7 → 32 of 50 admitted median 8 runs to first failure 8 rescued by reflection

    An RSU relay chain lets the vehicle know about junctions beyond its own radio range.

    0.5 → 2.6 junctions known ahead stops 1.9 → 1.0 420 runs, 0 collisions

    Cooperation can be measured, and it only works when both vehicles are equipped.

    EEBL relay: 7/10 → 0/10 crashes IMA: clean yield in 10/10 seeds
