The idea

The car never sees the world. It sees messages.

Every V2X decision runs on a belief rebuilt from messages. A failure can come in anywhere along this chain.

Method

One prompt in, one minimal failure out

The LLM interprets the prompt. Fixed rules check feasibility and decide whether a failure counts.

  1. 01

    LLM Agent Analysis

    Parses the prompt into a typed spec. An Age-of-Information check rejects faults that cannot matter.

  2. 02

    Scenario Grounding

    Retrieves road, V2X and driver knowledge. The planner assigns agents to real lanes.

  3. 03

    V2X Synthesis

    SPaT, MAP and BSM pass through a spatial channel and fault injection, next to a ground-truth twin.

  4. 04

    Refinement

    Search and LLM self-reflection repair weak tests. Delta debugging reduces each failure to one fault.

Paired rollout replay

What the experiments show
